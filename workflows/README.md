# n8n workflows

The onboarding workflow exports will live here. Planned workflow set:

1. `01_setup_check.json` — validate required credentials, spreadsheet tabs, and profile document configuration.
2. `02_capture_to_memory.json` — normalize an incoming note into a memory/action/project record.
3. `03_daily_review.json` — summarize open actions, stale items, and upcoming reviews.
4. `04_memory_maintenance.json` — deduplicate, archive, and request confirmation before changing durable memory.

Workflow exports must contain placeholders rather than personal credentials or document IDs.
